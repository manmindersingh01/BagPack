# Backpack 🎒

Backpack is a file management system built in Next.js, allowing users to upload and retrieve up to 50 GB of data via Firebase. Integrated Clerk for user authentication.

## 🌐 Live
[https://bag-pack-avkm.vercel.app/](https://bag-pack-avkm.vercel.app/)

## 🛠️ Tech Stack
- Next.js
- Firebase Firestore
- Firebase Storage
- Clerk (Auth)

## ✨ Features
- Upload & organize large files
- Authentication via Clerk
- Firestore metadata storage
- Firebase Storage with rules
